MoonBit · Native · Provider-neutral

用 MoonBit 写 AI， 不牺牲原生性能。

MoonAI 把 Vercel AI SDK 的核心抽象带到 MoonBit：统一的模型接口、流式事件、 多步工具调用与 MCP 客户端，全部运行在 native async 运行时之上，没有 Node.js、没有桥接层。

Capabilities

一套接口，覆盖完整的模型生命周期

从一次文本生成，到多步工具循环、结构化输出、媒体模型与 MCP 会话，接口保持一致， provider 之间的差异被收敛在边界内。

01

Provider 中立

统一 LanguageModelV4 契约，OpenAI、Anthropic、Google、DeepSeek、阿里、MiniMax、xAI 等实现可互换。

02

多步工具调用

generateText / streamText 驱动完整 agent 循环：工具输入流、执行、结果回灌与停止条件。

03

流式优先

统一的流事件词汇表，SSE 增量解析、事件批处理与取消传播由 SDK 负责，调用方只处理语义事件。

04

结构化输出

generateObject 与 JSON Schema 校验，失败时保留原始值并给出可诊断的 APICallError。

05

多模态模型

文本、图像、视频、语音、转录、Embedding 与 Reranking 都有独立的 V4 模型边界。

06

MCP 与 Harness

内置 MCP 客户端（stdio / HTTP / SSE）与 OpenCode、Pi、DeepAgents 会话桥接适配器。

Architecture

四层，边界清晰

上层只依赖 trait，下层负责协议、序列化与网络。替换任意一层，其他层保持不变。

应用

CLI Agent · Web 后端 · 工作流编排

@ai

generateText · streamText · generateObject · Agent · Tool

@provider

LanguageModelV4 / ImageModelV4 / VideoModelV4 / EmbeddingModelV4 …

运行时

moonbitlang/async · socket · TLS · SSE · stdio

V4

每个 provider 通过 pub impl 实现模型 trait，再以显式 pub extend 暴露方法。 没有宏魔法，接口即文档。

Quickstart

三分钟跑通第一次生成

1

声明依赖

name = "demo/agent"

import {
  "QuietlyChan/moonai@0.2.0",
  "moonbitlang/async@0.22.7",
}

preferred_target = "native"
2

编写一次调用

///|
pub async fn main {
  let model = @openai.openai(
    "gpt-4.1-mini",
    api_key=@env.get_env_var(
      "OPENAI_API_KEY",
    ).unwrap(),
  )
  let result = @ai.generateText(
    model,
    prompt="用一句话解释 MoonBit。",
  )
  @io.println(result.text)
}
3

构建并运行

moon run .

产物是原生可执行文件。无需 Node.js，无需打包器，密钥只存在于进程内。
